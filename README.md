# SENSIRUPT

Sensible Disruption for Technology Leaders.

A light-theme, minimal, premium marketing website for **Sensirupt** — a boutique techno-legal/IP advisory firm bridging Silicon Valley intelligence with Indian innovation.

## 🚀 Features
- **Hero Canvas**: Viewport-fitted sky painting backdrop featuring Lady Justice with fluid floating animations.
- **Glassmorphism UI**: Frosted-glass search bar with live consultation briefing booking.
- **Structured Sections**:
  - About Us with horizontal key statistics
  - 4-Column Practice Area Grid
  - 6-Card Ventures & Breakthrough Portfolio
  - High-Contrast Confidential Advisory Enquiry Modal
- **Tech Stack**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Framer Motion.

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
